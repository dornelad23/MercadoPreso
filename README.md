# Mercado Preso

Marketplace Android desenvolvido em Kotlin com Jetpack Compose.

> Preços que você não consegue escapar.

## Funcionalidades

- Home de marketplace
- Busca de produtos
- Categorias
- Produtos em destaque
- Tela de detalhes
- Adição ao carrinho
- Controle de quantidade
- Remoção de produtos
- Cálculo de frete por CEP (simulado)
- Cálculo de subtotal e total
- Perfil
- Navegação inferior
- Arquitetura organizada por domínio

## Tecnologias

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- ViewModel/Lifecycle
- Gradle Kotlin DSL

## Observação

O pagamento não faz parte do escopo atual. O fluxo termina no carrinho e cálculo de frete.

## Pacote

`com.example.mercadopreso`
